# Week 6 – Asynchronous JavaScript

## Overview

This repository contains my Week 6 JavaScript assignments. During this week, I learned how JavaScript handles asynchronous operations using callbacks, promises, promise chaining, async/await, and browser storage with localStorage.

The exercises helped me write cleaner, more maintainable code while improving my understanding of modern JavaScript.

---

## Learning Objectives

* Understand synchronous vs asynchronous JavaScript
* Work with callback functions
* Convert callbacks to Promises
* Chain multiple Promises
* Use async and await
* Handle errors with try...catch
* Debug JavaScript applications
* Apply clean code practices
* Store and retrieve data using localStorage
